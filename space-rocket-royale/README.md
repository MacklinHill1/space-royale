# Space Rocket Royale

**[Play now →](https://space-rocket-royale.vercel.app)**

Free browser space shooter with wave survival, epic boss fights, roguelite upgrades, and Boss Rush mode. No download required — runs in any modern browser.

## Game modes

- **Endless Survival** — infinite waves with full progression
- **Boss Rush** — a new boss every 60 seconds
- **Speed Farm** — 3× XP and gold
- **Hardcore** — 60 HP, no second chances
- **Time Attack** — 10-minute score sprint

## Controls

| Input | Action |
|-------|--------|
| WASD / Arrows | Move |
| Mouse | Aim |
| Click | Shoot |
| Shift | Dash |
| Q | Bomb |
| F | Magnet |
| E | Upgrade shop |

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## Tech stack

- [Next.js](https://nextjs.org) App Router
- HTML5 Canvas game engine
- [Vercel](https://vercel.com) deployment
